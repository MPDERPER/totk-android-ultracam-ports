# UltraCam 3.0.0 Android package

The 3.0.0 asset contains unchanged upstream `main.npdm` and `subsdk3` files matching tag `manager-3.2.0`. Its separate configuration lives on the virtual SD card at `sdmc/UltraCam/TOTK/Config/`.

Upstream describes 3.0.0 as a major Calamity rewrite with an in-game menu and current 1.4.2 support. The controller shortcut is hold **ZL + ZR**, then press **L3**; F12 is the upstream keyboard alternative.

My reported readings were 40 FPS in an overworld test and 55 FPS in a shrine test. See [benchmarks.md](benchmarks.md) for limitations.
