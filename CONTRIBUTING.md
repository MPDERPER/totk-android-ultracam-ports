# Contributing

Bug reports should include the Android device, SoC/GPU, Eden build, TOTK update, UltraCam version, GPU driver, enabled mods, configuration path, and reproduction steps. State whether frame generation is enabled and whether an FPS reading is rendered or generated when known.

Do not upload copyrighted game files, firmware, keys, game updates, or third-party binaries without verified redistribution permission. Keep performance reports tied to a reproducible scene and disclose temperature, driver, and emulator settings when possible.
